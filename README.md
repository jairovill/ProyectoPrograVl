Librería Herrera – Online Bookstore

About the Project

This is a university project developed for Librería Herrera, a bookstore located in San Ramón, Costa Rica.

The main idea was to create a website where customers could browse books and make purchases online instead of relying only on the physical store.

Technologies Used

- C#
- ASP.NET Core MVC
- SQL Server
- Entity Framework Core
- HTML, CSS and JavaScript
- Visual Studio 2022

Main Features

- Book and author management
- Book categories
- User accounts and roles
- Shopping cart
- Order management
- Payment methods

Database

The project uses SQL Server to store and manage the application data.

The database script is located in:

`Database/ProyectoPrograVI.sql`

How to Run

1. Clone this repository.
2. Open `ProyectoPrograVI.sln` in Visual Studio 2022.
3. Configure your SQL Server connection.
4. Build and run the project.
